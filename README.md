# 🏁 Math Racers

A racing-themed arithmetic game for kids built with [Phaser 3](https://phaser.io/).

Race go-karts, stock cars, and supercars by solving math problems — correct answers give you speed boosts, streaks trigger nitro, and trophies unlock new cars and tracks.

## Status

🚧 **In planning** — see [DESIGN.md](DESIGN.md) for the full game design document.

## Tech Stack

- **Engine:** Phaser 3 (HTML5/Canvas/WebGL)
- **Language:** JavaScript (may migrate to TypeScript later)
- **Target:** Kindle Fire (Silk browser), works on any modern browser
- **Art:** AI-generated cartoon assets
- **Audio:** Web Audio API via Phaser
